# 配置说明：work/build_character.json

`prepare.sh` 生成这个文件：头的部分来自头部档案，身体的部分来自测量（`work/measure/measure.json` 里记着每个值依据的原始数据），其余用两套已交付衣服的默认值。生成后可以手改；再次运行 `prepare.sh` 要加 `--force`，旧文件会改名保留，但不会读取旧文件里的手调值。需要保留的值写进 `work/build_overrides.json`。

坐标单位是米，Z 朝上，-Y 是模型正面。设了 `frame` 时，所有与头部有关的位置都写在头部档案的坐标里（`x_档案 = (x - t) / s`），身体部分的数值也在这个坐标里测量。

## 基本

| 键 | 含义 |
|---|---|
| `kit` | Charakuru 套件根目录 |
| `rig`、`collection` | 权重结果里的骨架和集合名（`CharaKit_Weights_<id>_Rig`） |
| `assembly_blend` | 套件组装结果，取头发用 |
| `frame` | 换到头部档案坐标的缩放和位移，见头部档案 |
| `hair_affine` | 新的头：这个项目自己的组装变换，头发按它放置后再换到档案坐标 |
| `keep_meshes` | 除 Body、Head 以外要保留的网格（裙子、丝带、抽绳等） |
| `output_blend`、`spring_config_out`、`report_out` | 输出 |

## 头和脸

| 键 | 含义 |
|---|---|
| `head_affine` | 组装空间到最终位置的变换，从权重结果的头部顶点拟合 |
| `head_texture`、`hair_texture`、`hair_texture_clean` | 头部档案的贴图 |
| `skull` | 闭合头壳：中心、贴合范围、后颈、眼眶留空 |
| `neck_loft` | 脖子过渡：脖子轴心、起点高度、外扩幅度 |
| `jaw_round`、`crease` | 下颌圆化、折痕 |
| `hair_cavity_box` | 删除嘴鼻附近头发碎片的范围 |
| `eye_white_fill` | 眼白补画 |
| `brow_overlay`、`face_fx` | 透眉、二次元贴片 |
| `earring` | 耳坠：位置范围和物理参数 |
| `iris_layer` | 虹膜画在眼球上的头：切成虹膜层（每只眼一个 `EyeIris_R/L` 材质）和眼皮层，视线平移虹膜贴图 |
| `mouth_open` | 「啊」张开高度上限，嘴宽倍数（写实脸可从 0.6 倍、二次元约 1.1 倍开始）。只缩小 `aa/ih/ou/ee/oh/happy_mouth/surprised_mouth`；不设时新头仍可能经 `MOUTH_GAIN` 缩小 |
| `mouth_mood` | 生气、难过口型的自然幅度上限：`width`、`open`、`arc`、`rise`、`drop`（按嘴宽计）、`angry_frown`；`false` 关闭 |

## 手和身体

| 键 | 含义 |
|---|---|
| `template_hand` | 拟合好的模板手和切口位置（`polish/hand/` 生成） |
| `finger_clean` | 手指权重清理的起点 |
| `helper_bones` | 腕部辅助骨。`mode: band`：手腕一根辅助骨（长袖）；`mode: twist`：前臂分 `count` 段扭转，从前臂 `start` 处开始（前臂露在外面时自动用） |
| `crotch_blend` | 裤裆权重：中线、裆底、髋关节高度、半宽，胯骨最低占比 `pelvis_min` |
| `hand_skin` | 手和脖子肤色统一（换装时脖子交给 `region_paint`） |
| `waist_blend` | 腰部各层共用的躯干权重比例 |
| `cuff_lining` | 袖口衬里补画和删除；只在模板手替换原手时启用。保留原手时移除或设 `false`，否则同材质同颜色的手会被误删 |
| `region_paint` | 按网格零件补色：`cloth`（衣服零件去肤色）、`band`（腰带这类同色带）、`underside`（指定零件朝下的面）、`skin`（皮肤零件统一肤色）、`metal`（小配件上色）。零件用「离某一点最近的面所在的零件」选定。`cloth` 还会处理四个方向都看不到的面（`lift_hidden`）和同材质同颜色的相邻零件（`siblings`） |

## 自动测量的规则

| 键 | 怎么量 |
|---|---|
| `frame` | 同一个头：头部顶点和档案 `head_rest.npy` 逐点拟合；新的头：眼角、嘴角、嘴中心、鼻尖、下巴和档案的同名点拟合 |
| `neck_loft.axis`、`z_flare`、`z_neck` | 喇叭口起点在头部最低点上方 2 mm；直筒段从前领口下 2 mm 开始（不高于喇叭口下 3 cm）；轴心是该高度脖子截面的中心 |
| `hair_colliders`（身体部分） | 脖子、上胸、两肩骨骼位置加固定偏移，按两肩间距缩放 |
| `finger_clean.x_min` | 四指指根关节最外侧再往外 5 mm |
| `waist_blend.z` | 髋骨上方 3 cm 到脊椎骨上方 3.5 cm |
| `cuff_lining` | 长袖且有袖子材质、已用模板手替换原手时开启；起点肘部内 6 cm，删除起点手腕内 7.5 cm |
| `helper_bones` | 前臂露在外面（短袖）用 `twist`，否则 `band` |
| `crotch_blend` | 髋关节以下、两腿之间的中线顶点超过 20 个时开启（裤子、短裤） |
| `skirt`、`ribbon` | 套件分类里的揺れ物；摆动起点从顶部往下：裙子、抽绳 15%，蝴蝶结 35% |
| `region_paint` | 在脖子、胸前、腹部、后背、胯部、大腿、小腿、上臂、前臂取零件：脖子零件自动按皮肤；冷色、少有暖色面的大块衣服自动去肤色；衣服顶部一圈深色（腰带）自动加 `band`；其余看零件图用 `--skin`、`--cloth` 指定，项链类小件用 `--metal` |

只看颜色分不出皮肤零件和粉色、米色衣服零件（紫色版腰前的粉色蝴蝶结肤色占比 82%，牛仔装露腰只有 49%），所以皮肤零件除脖子外都要看图决定。

## 物理

| 键 | 含义 |
|---|---|
| `hair` | 头发分链：根部高度、方位角、骨数、前发单独设置 |
| `skirt` | 裙子分链（没有裙子时省略） |
| `ribbon` | 丝带、抽绳：网格名、骨名前缀、父骨、根部高度 |
| `hair_colliders` | 头发碰撞球：头、脖子、上胸、两肩 |

仓库未附紫色版、牛仔装的完整项目配置。先用 `prepare.sh` 生成本角色的配置，再按测量结果调整；不要照抄其他角色的绝对坐标。

## 保留手调配置

- **现象**：`prepare.sh --force` 后嘴、脖子、袖子或肤色恢复默认。
- **原因**：生成器读取 `profile.json`、`measure.json`、命令行和覆盖文件，不合并旧 `build_character.json`。`mouth_open`、`mouth_mood` 不在头部档案复制白名单；`iris_layer` 由新头分支建立，没有完整的同头档案往返支持。
- **处理**：在项目的 `work/build_overrides.json` 保存手调值。每次生成配置时嵌套对象逐键合并，普通数组键和标量整体替换；带 `+` 后缀的数组键追加到生成列表，例如 `"region_paint": {"cloth+": [...]}`。`false` 只用于代码明确支持关闭的项，不是通用删除语法。
- **配置键**：`work/build_overrides.json`，人物2可用下面的完整示例。

```json
{
  "mouth_open": 0.6,
  "neck_widen": {"factor": 1.1}
}
```

`neck_widen.factor` 等同 `prepare.sh --neck-widen 1.1`，代表宽度 1.1 倍。它是合并例外：生成器先取 factor，再按测量重算 `z_from/ramp`，不合并覆盖文件中的这两个字段；显式非 1.0 的命令行 `--neck-widen` 优先。输出路径 `output_blend/spring_config_out/report_out` 和 `generated` 也由生成器最后写入，不由覆盖文件保留。

紫色版通过覆盖文件保留 `arm_joints`、`cuff_follow`、`skirt_leg_follow`、`sleeve_fit`、`hand_skin` 和 `safety_shorts`。这些值依赖本角色测量，不提供通用绝对坐标。

## 按现象选择新增配置

| 现象 | 原因 | 处理 | 配置键和单位 |
|---|---|---|---|
| 脖子偏细 | 生成比例与参考不同 | 在过渡起点以上渐变加粗 | `neck_widen.factor` 倍数；`z_from` 起点 m、`ramp` 过渡长度 m |
| 放下手臂时袖子钻进身体 | 骨骼关节偏离袖子中心 | 移动关节并保持骨链相连 | `arm_joints`：按 `shoulder/upper_arm/lower_arm/hand` 写 `[y,z,可选x]`，单位 m；x 按左右侧取符号，省略则保留 |
| 翻腕时袖口穿手 | 袖口只跟前臂 | 袖口分配部分手权重 | `cuff_follow.back/front/full_at`：相对腕关节沿前臂轴的距离 m，back 向肘、front 向手，full_at 为达到最大权重处；`max` 权重比例 |
| 裙子不跟腿、贴身处穿出 | 弹簧权重与身体运动不同 | 按高度和方位给裙子增加腿权重 | `skirt_leg_follow.z_full/z_top` 满权重/零权重高度 m；可选 `z_off/z_zero` 在下方淡出至零的高度 m；`angle/width` 方位中心/范围 °；`max` 权重比例 |
| 裙腰、臀部贴身处穿模 | 裙子与身体权重不同 | 从最近身体表面转移权重 | `skirt_contact.materials` 身体材质名列表；`z_max` 选面高度 m；`full/none` 满影响/零影响距离 m |
| 蓬袖放下后穿躯干 | T 字姿势的袖子形状不适合垂臂 | 多姿势贴合，保留肩和袖口接缝，装饰跟随袖面 | `sleeve_fit`，字段见下表 |
| 其他衣服区域露出肤色内衬 | 投影染色 | 指定区域补色或删除；保留原手时不要把手纳入选区 | `lining_regions[]`，字段与 `cuff_lining` 相同 |
| 裙下缺安全裤 | 贴图未绘制 | 在 `polish.sh` 表情后、关节修正前绘制，只改贴图 | `safety_shorts.hem` 髋到膝的比例，默认 0.26；`material` 默认 `Material_lower_body`；`palette` 默认 `lavender`，也支持 `cream` |
| 脸壳张嘴露板边 | 浅背板挡不住侧面 | 默认生成封闭口腔袋；整头使用已有口袋 | `mouth_bag`，`false` 仅使脸壳退回旧背板 |

安全裤示例：`"safety_shorts": {"hem": 0.5, "material": "Material_lower_body", "palette": "lavender"}`。`hem: 0.5` 是髋到膝的 50% 位置，不是 0.5 m。

### 袖子贴合字段

| 字段 | 含义 |
|---|---|
| `targets` | 参与避让的区域名列表，如 `torso`、`waist`、`skirt`，需与本模型区域对应 |
| `passes`、`smooth` | 贴合轮数、每轮平滑次数 |
| `poses` | `[down,swing,flex]` 数组列表，分别为手臂放下、前后摆、肘弯角度，单位 ° |
| `seam_rings` | 肩和袖口固定的邻接环数 |
| `deco_max_verts` | 小于此顶点数的独立装饰按袖面整体跟随 |
| `reach`、`max` | 表面查询距离、最大位移，单位 m |
| `gap` | 按目标区域名给出间隙，单位 m |
| `min_radius_frac` | 压缩后距手臂轴的半径不得低于原半径的此比例 |

### 嘴部字段

| 键 | 默认值与含义 |
|---|---|
| `mouth_mood.width` | 1.0 倍闭嘴宽度；限制生气、难过嘴宽 |
| `mouth_mood.open` | 0.03 个嘴宽，唇缝张开上限 |
| `mouth_mood.arc` | 0.10 个嘴宽，嘴弧度上限 |
| `mouth_mood.rise` | 0.04 个嘴宽，上唇中间抬起上限 |
| `mouth_mood.drop` | 0.06 个嘴宽，嘴角下移上限 |
| `mouth_mood.angry_frown` | 0.8 倍难过形变，用于替换幅度过大的龇牙式生气 |
| `mouth_mood: false` | 关闭上述自然幅度限制 |
| `mouth_bag.rim_x/rim_z` | 1.35 / 0.9 个半嘴宽，袋口左右/上下半径 |
| `mouth_bag.behind` | 0.003 m，即皮肤后 3 mm |
| `mouth_bag.depth` | 1.1 个嘴宽，向内深度 |
| `mouth_bag.rings/around` | 8 圈、每圈 48 点 |
| `mouth_bag.low_band` | 0.6 个半嘴宽，袋壁跟下唇的上下混合带宽度 |

`mouth_open` 的缩放系数封顶 1.0，不会放大已有口型。嘴宽另受可见嘴角范围限制；导演台用 `extras.vrmPolish.mouthWidth` 和 `mouthNarrow` 收回组合口型超宽部分。人物2嘴宽/瞳距为静止 0.52、微笑 0.61；参考静止约 0.76、微笑偏好 0.55–0.62，不能代替本角色审美验收。

## 已有模块的字段索引

以下是构建实际读取的字段。坐标、半径、距离除特别说明外用档案坐标的 m；角度用 °，权重、颜色和增益是无量纲值。纹理平滑尺度用像素，网格环数、邻居数、采样数用整数。模块透传字段以对应 `polish/face/` 实现为准，不把模块名当完整参数。

| 配置块 | 字段与作用 |

| `crease_pairs` | 折痕顶点对 JSON 路径；主构建无条件读取，新头也生成自己的文件 |

## 流水线文件与环境

| 输入 | 作用 |
|---|---|
| `work/skirt-colliders.json` | 套件 `scripts/plan-skirt-colliders.py` 的方案；存在时由 `build.sh` 调套件 `apply-skirt-colliders.py` 应用 |
| `work/skirt-extra-colliders.json` | 存在时再由 `polish/post/add_skirt_colliders.py` 加手臂和手碰撞 |
| `KIT` | Charakuru 根目录，未设时按项目目录推导 |
| `BLENDER` | Blender 可执行文件，默认 macOS 应用路径；修改路径不等于已支持其他平台 |
| `APP_URL` | 请求登记地址，默认 `http://localhost:8780` |

`prepare.sh` 参数包括 `--skin`、`--cloth`（零件图编号）、`--metal`、`--neck-widen`、`--force`。需要 Python 3 + numpy + Pillow，精修入口需要 macOS 和 zsh；套件脚本另需 Node.js 22、Blender 5.2 + VRM Add-on。入口已启用 `set -e` + `pipefail`，但仍有容错包装例外，见[配合 Charakuru](配合Charakuru.md)。
